# Стіл проєктування (Drafting Table) для Stardew Valley 1.6

C#-мод для SMAPI. Протестований тільки на збірку, у грі ще не запускався.
Цільова платформа: Android (SMAPI for Android 1.1.7, Stardew Valley 1.6.15), має працювати й на ПК.

## Що робить

- Додає предмет **«Стіл проєктування»**. Один стіл дається безкоштовно, коли вперше завантажуєш сейв із модом. Ще можна купити в Робін за 500з.
- Постав стіл і торкнися його. Відкриється вигляд ферми згори:
  - **Огляд.** Тягни карту пальцем, зводь і розводь два пальці для масштабу (або кнопки `-` / `+`). Тут є кнопка «Забрати стіл».
  - **Будівлі.** Ті самі будівлі, що в меню Робін. Вибери будівлю, торкнися карти, щоб поставити привид, потім «Будувати». Списуються гроші й матеріали, Робін будує стільки ж днів і **лише одну будівлю за раз**, як у грі.
  - **Розставити.** Будь-що з рюкзака, що ставиться надворі: доріжки, паркани, машини, декор, спринклери, ліхтарі. Торкнись клітинки, щоб поставити. Затисни й веди пальцем, щоб малювати доріжку чи паркан. Карта рухається двома пальцями.
  - **Прибрати.** Повертає в рюкзак те, що ти поставив: доріжки, паркани, машини, декор. Машини, які зараз працюють, і непорожні скрині не прибираються.
- Усе ставиться на справжню ферму, тож гра зберігає зміни разом із сейвом.

## Встановлення (Android)

1. Розпакуй `dist/DraftingTable-1.0.0.zip`.
2. Скопіюй папку `DraftingTable` у папку `Mods` свого SMAPI for Android. Шлях показує сам лаунчер, зазвичай це щось на кшталт `Android/data/abc.smapi.gameloader/files/Mods`.
3. Запусти гру через SMAPI.

## Налаштування (`config.json` з'явиться після першого запуску)

| Параметр | За замовчуванням | Що означає |
|---|---|---|
| `Language` | `auto` | `auto`, `uk`, `ru` або `en`. Якщо гра англійською, а тобі потрібна українська, постав `uk` |
| `OpenMenuKey` | `None` | клавіша, яка відкриває планувальник будь-де (для ПК, наприклад `F8`) |
| `GiveFreeTable` | `true` | чи давати один стіл безкоштовно |
| `ShopPrice` | `500` | ціна в Робін (`0` прибирає стіл з її магазину) |

> Шрифти гри можуть не мати літер `і ї є ґ`. Тоді мод автоматично підставить схожі (`i`, `е`, `г`), щоб гра не впала.

## Обмеження першої версії

- Покращення будівель (Великий курник тощо) і перенесення будівель поки робляться через саму Робін.
- Меблі в список «Розставити» не потрапляють.
- Мод збирався без файлів гри: до гри він звертається через reflection. Якщо щось не працює, надішли лог SMAPI (`ErrorLogs/SMAPI-latest.txt`), там будуть рядки з `[Drafting Table]`.

## Збірка

```bash
./build.sh   # потрібен .NET 6+ SDK; результат: dist/DraftingTable-<версія>.zip
```

`stubs/` містить лише заглушки для компіляції. Вони не потрапляють у мод: у грі використовуються справжні SMAPI і Stardew Valley.
