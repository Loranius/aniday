# Телеграм за номером телефону

Маленький додаток: вводите номер → отримуєте посилання на Telegram-акаунт.

## Два режими

### 1. Без перевірки (тільки `index.html`)
Відкрийте `index.html` у браузері (або викладіть на будь-який статичний хостинг).
Номер нормалізується (`+380 67 123-45-67`, `0671234567`, `671234567` → `380671234567`)
і формується посилання `https://t.me/+380671234567`.

Telegram відкриє акаунт за цим посиланням, **якщо він існує** і власник дозволив
знаходити себе за номером (Налаштування → Конфіденційність → Номер телефону →
«Хто може знайти мене за номером»). Чи існує акаунт — у цьому режимі не перевіряється:
Telegram не дає такої інформації без авторизації.

### 2. З перевіркою існування (`server.py`)
Бекенд через **ваш** Telegram-акаунт (Telethon) тимчасово додає номер у контакти,
дізнається, чи є такий користувач, і одразу видаляє контакт. Якщо в людини є
юзернейм — посилання буде `https://t.me/<username>`, інакше `https://t.me/+<номер>`.

```bash
cd tg-link
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt
export TG_API_ID=...  TG_API_HASH=...   # створіть додаток на https://my.telegram.org → API development tools
python server.py                         # перший раз попросить номер і код підтвердження
```

Відкрийте http://127.0.0.1:8080 — сторінка сама знайде бекенд.
Якщо сторінка лежить окремо: `index.html?api=http://127.0.0.1:8080`.

API: `GET /api/check?phone=380671234567` →
```json
{ "exists": true, "phone": "380671234567", "id": 123, "username": "name", "name": "Ім'я", "link": "https://t.me/name" }
```

### Обмеження
- `exists: false` означає «не знайдено»: номера може не бути в Telegram, **або** людина
  приховала себе налаштуваннями приватності.
- Telegram обмежує кількість імпортів контактів; при перевищенні сервер поверне 429
  з часом очікування. Для масових перевірок інструмент не призначений — часті запити
  можуть призвести до обмежень акаунта.
- Файл `tg_session.session` — це доступ до вашого акаунта. Не комітьте й нікому не передавайте
  (уже в `.gitignore`). Сервер за замовчуванням слухає лише `127.0.0.1`.
